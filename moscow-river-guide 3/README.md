# Вниз по течению — путеводитель по Москве

Статический сайт (HTML + CSS + JS, без сервера и сборки). Карта — Leaflet + OpenStreetMap,
фотографии подгружаются из Википедии.

## Как выложить на Vercel

**Вариант 1, без командной строки:**
1. Залейте папку в репозиторий на GitHub.
2. На vercel.com нажмите **Add New → Project**, выберите репозиторий.
3. Framework Preset: **Other**, Build Command оставьте пустым. Нажмите **Deploy**.

**Вариант 2, через CLI:**
```
npm i -g vercel
cd moscow-river-guide
vercel --prod
```

## Как редактировать
- Тексты, координаты и остановки лежат в `data.js`.
- Свои фото: положите в `photos/` файл с именем остановки, например `photos/kremlin.jpg`.
  Тогда он заменит фото из Википедии. Список id есть в `data.js`.
- Старые фото для переключателя «Сейчас / Раньше»: положите в `photos/` файл `<id>-old.jpg`,
  например `photos/novodevichy-old.jpg`, и впишите подпись с годом в `data.js`:
  `old: { caption: "Новодевичий монастырь, 1910-е" },`.
  Без старого фото переключатель на карточке просто не появляется.
  Где искать датированные снимки Москвы: https://pastvu.com (с указанием года и места).
